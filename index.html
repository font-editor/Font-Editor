Make your own font online for free

  1. Pick a character set and give your font a name.
  2. Choose Vector or Pixel mode and draw each character in the editor.
  3. Adjust spacing with the character width slider and check the live preview.
  4. Export a TTF file and install it on your computer.

Vector, pixel or raster font?

Vector mode gives smooth, hand-drawn letters, great for handwriting and script styles. Pixel mode snaps everything to a grid for retro, blocky fonts. Raster mode paints onto a bitmap like a paint program, so you can erase part of a stroke, and it is converted to outlines when you export.

Install your font

On Windows, right-click the .ttf file and choose Install. On Mac, double-click it and choose Install Font. It then shows up in Word, Photoshop, Canva desktop and other apps.

Curves, kerning and custom characters

Draw precise outlines with Bezier handles, adjust the space between letter pairs with kerning, and upload your own character set as a text file to add accents or any alphabet.

FAQ

Is Font Editor free?

Yes. Font Editor is free to use, runs in your browser and needs no account or sign-up.

Can I make a pixel font?

Yes. Switch to Pixel mode, pick a grid size and click or drag to fill squares. Vector mode gives smooth freehand lines instead.

How do I install my font?

Export the .ttf file. On Windows, right-click it and choose Install. On Mac, double-click it and choose Install Font.

Can I turn my handwriting into a font?

Draw each letter with a mouse, finger or stylus in Vector mode, then export. Spacing and size can be adjusted per character.

Is my work uploaded anywhere?

No. Drawing happens locally in your browser. Use Save project to keep an editable backup file.

Everything happens locally in your browser. TTF export loads the OpenType.js library from a CDN, so you need an internet connection to export. Save your project JSON regularly as an editable backup.
